# rosettex skill for Claude Code

This plugin adds the **rosettex** skill: it teaches Claude how to translate a whole scientific paper, from its TeX
source or from a born-digital PDF, into another language with the rosettex command-line tool, and how to return a PDF
that keeps the paper's own layout, formulas, figures, citations and links. Claude does the translating; rosettex prepares
question sheets, checks every answer and typesets the result.

## What it runs, sends and fetches
The plugin itself contains only this skill (Markdown). It runs nothing on install and has no MCP server or scripts.
When you ask for a translation, Claude runs the `rosettex` command that you installed yourself, in the work folder you
choose. That tool goes online only to download a paper you give as an arXiv ID (arxiv.org) and, once, after you agree, to
download its TeX toolchain (github.com and mirror.ctan.org). Local papers are never uploaded and nothing is collected.

## Requirements
The `rosettex` command must be installed: see the project's install instructions at
https://github.com/20235106-huynk/rosettex#-manual-install. Privacy: https://github.com/20235106-huynk/rosettex/blob/main/PRIVACY.md
