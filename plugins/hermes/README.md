# rosettex for Hermes

The slim Hermes package of rosettex: the skill and the MCP launcher only (no source, fonts or pyproject.toml, which
Hermes' scan and dependency resolver reject in the full repository). Needs uv on PATH.

    hermes plugins install file:///path/to/rosettex-clone#plugins/hermes
    hermes plugins enable rosettex

Generated by `python -m rosettex.skill`; do not edit by hand.
